# mac-quicklook

Awesome QuickLook Plugins
===

A curated list of modern macOS QuickLook plugins, built on Apple's current sandboxed App Extension (`.appex`) architecture. No legacy `.qlgenerator` plugins, which are deprecated and no longer supported on macOS 15 Sequoia and later.

All apps are downloaded from the Mac App Store. Sorted alphabetically, with the price (or **Free**) listed beside each one.

Inspired by [awesome-mac](https://github.com/jaywcjlove/awesome-mac).

## QuickLook Plugins

* [FinderPeek](https://apps.apple.com/us/app/finderpeek-quick-code-viewer/id6761670824?mt=12) - Instant previews for source code, JSON, and config files, with syntax highlighting for 30+ languages. **$4.99**
* [Folder Preview](https://apps.apple.com/us/app/folder-preview/id6698876601?mt=12) - Quick Look inside folders and archives (zip, tar, gz, 7z, rar) in Finder. **$2.99**
* [Folder Quick Look](https://apps.apple.com/app/id6753110395) - Instant folder and archive previews, with Markdown file support. **$3.99**
* [FolderPreview - Preview Folder](https://apps.apple.com/us/app/folderpreview-preview-folder/id6752695008?mt=12) - Preview folder and archive contents in Finder without extracting them first. **Free**
* [GIS Quick Viewer](https://apps.apple.com/us/app/gis-quick-viewer/id6762661962?mt=12) - Spatial data previews for GeoJSON, KML, KMZ, GPX, and Shapefile, with interactive maps and attribute inspection. **$5.99**
* [LUT Preview](https://apps.apple.com/app/id6759214495) - Quick Look LUT files and preview their color-grading effect on a sample image. **$4.99**
* [Markdown Preview - Quick Look](https://apps.apple.com/app/id6739955340) - Renders Markdown, KaTeX math, Mermaid diagrams, and TextBundle files in Quick Look. **$2.99**
* [Marked QL - Markdown Preview](https://apps.apple.com/us/app/marked-ql-markdown-preview/id6787414592?mt=12) - Instant Markdown previews in Quick Look, powered by Marked's Apex processor. **$9.99**
* [Mottie](https://apps.apple.com/app/apple-store/id6743446238?pt=120474400&ct=awesome-mac&mt=8) - Quick Look extension and native player for Lottie and dotLottie animation files. **Free**
* [Peek — A Quick Look Extension](https://apps.apple.com/us/app/peek-a-quick-look-extension/id1554235898?mt=12) - Adds text selection, search, jump-to-line, and syntax highlighting across 300+ file types in Quick Look. **$7.99**
* [Peekdown](https://apps.apple.com/us/app/peekdown/id6757321612?mt=12) - Preview and annotate Markdown and MDX files with GitHub-style formatting in Quick Look. **$3.99**
* [PreviewCode](https://apps.apple.com/us/app/previewcode/id1571797683?mt=12) - Quick Look source code preview and icon thumbnailing for dozens of programming languages. **$2.99**
* [PreviewJson](https://apps.apple.com/us/app/previewjson/id6443584377?mt=12) - Quick Look previews and icon thumbnails for JSON files, with adjustable indentation and colors. **$1.99**
* [PreviewMarkdown](https://apps.apple.com/app/previewmarkdown/id1492280469) - Quick Look previews and icon thumbnails for Markdown files. **$2.99**
* [PreviewText](https://apps.apple.com/us/app/previewtext/id1660037028?mt=12) - Quick Look previews and icon thumbnails for text files without a standard extension. **Free**
* [PreviewYaml](https://apps.apple.com/us/app/previewyaml/id1564574724?mt=12) - Quick Look previews and icon thumbnails for YAML files. **$1.99**
* [Quick Data Insights](https://apps.apple.com/us/app/quick-data-insights/id6764301485?mt=12) - Quick Look for Parquet, SQLite databases, and Jupyter notebooks, with schema views and SQL export. **$4.99**
* [QuickLook for IPA & APK](https://apps.apple.com/us/app/quicklook-for-ipa-apk/id6746680688?mt=12) - Inspect iOS and Android app packages (IPA, APK, AAB) directly in Finder. **$1.99**
* [Source Code Preview](https://apps.apple.com/kg/app/source-code-preview/id6759270528?mt=12) - Quick Look for source code and JSON, with syntax highlighting for 50+ languages. **$4.99**
* [Unfold - Quick Look Previews](https://apps.apple.com/us/app/unfold-quick-look-previews/id6760872758?mt=12) - Quick Look for 140+ file types, including folders, archives, source code, Markdown, ebooks, and comics. **$9.99**
